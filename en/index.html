Schumann resonance, measured

A Portuguese-language space weather monitor. This page explains, in English, what it measures and how.

The live dashboard on this site is written in Portuguese. This page exists so that English readers, and anyone deciding whether the data is worth citing, can understand what is being measured and how, without having to translate a panel first.

What is actually published here

Every 30 minutes a program downloads the public spectrogram from the Space Observing System at Tomsk State University, locates the most recent column of data, finds the peak of the fundamental inside the 6.6 to 9.2 Hz band, and records two things: the frequency of that peak, and its intensity.

The intensity comes from the colour bar printed on the image itself, on a scale of 0 to 100. It is not calibrated in picotesla, because the station does not publish a calibration. Comparing values between days is legitimate; converting them into physical units is not, and we do not do it.

Why read it from an image at all

Because there is no public source that publishes these values as numbers. We checked file by file: the Tomsk server returns content for the spectrogram image and empty files for every data endpoint we tried. The HeartMath network has no documented API.

That leaves two options. Read the image, and say so. Or invent the numbers. Sites publishing a live "F1 = 7.70 Hz" are doing one or the other, and it is worth knowing which.

The refusal rules, which are the point

A measurement is refused, rather than estimated, when:

  • the receiver at Tomsk is saturated and the whole band reads white, which happens roughly one hour in four;
  • the detected peak sits against the edge of the search band, meaning what was found is probably not the fundamental;
  • the colours in the image do not match the published scale;
  • the image changes dimensions, which is how a change of format at the station is detected.

When that happens the reading is marked as refused, with the reason, and the series shows a gap. Nothing is interpolated and nothing is filled in. Joining the two sides of a gap would draw a measurement that never existed.

When the current half hour has no usable reading, the dashboard steps back through the image, which covers 72 hours, until it finds the last reading it trusts, and displays that one with its age shown.

One thing worth knowing about the source

The old Tomsk address is frozen. Until September 2025 the spectrogram was published at sosrff.tsu.ru/new/shm.jpg. That file stopped updating on 1 September 2025 and is still online, unchanged. Several sites continue to publish it as if it were live. The live feed is now at sos70.ru, and that is the one used here. The dates printed along the top of the image let anyone verify this in a few seconds.

The data is open

The full series of measurements, covering the last 30 days, is available as a JSON file with no registration and no key. Each row holds the timestamp in UTC, the peak frequency in hertz, the intensity on the 0 to 100 colour scale, and the state of the reading. A null frequency means the reading was refused, and the state says why.
